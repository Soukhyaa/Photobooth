Vintage Booth 📸

A retro-inspired virtual photo booth that brings the charm of classic photo booths to your browser. Capture moments, customize photo strips, and save your memories.

✨ "Try Vintage Booth Live" (https://photobooth-bay-psi.vercel.app/)

Features

- Photo Booth: Capture photos using your device's camera.
- Live Photos: Capture still photos with accompanying motion clips.
- Photo Filters: Choose between Soft B&W and Golden Hour.
- Create a Strip: Import, arrange, crop, customize, and download photo strips.
- Pose Inspiration: Explore pose ideas for solo, couples, and friends.
- My Memories: Save and revisit your photos with seven-day storage.

Tech Stack

Frontend: React 19, Vite, JavaScript, CSS
Backend: Python, FastAPI, SQLAlchemy
Database: Neon PostgreSQL
APIs: Canvas API, Browser Media APIs
Deployment: Vercel, Render

Run Locally

Clone the repository:

git clone https://github.com/Soukhyaa/Photobooth.git
cd Photobooth

Install dependencies and follow the frontend and backend setup instructions in their respective directories.
